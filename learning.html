Now

From October 2026 to February 2027 I am going back over the foundations, with a focus on the parts I use less in my daily work: statistics, workflow managers and single-cell analysis.

  • From Cell Line to Command Line Ming "Tommy" Tang. Unix, R, statistics, PCA, heatmaps, Snakemake and reproducible research. Author's blog
  • 12 sed lessons and 60 Unix one-liners Ming "Tommy" Tang. Short daily exercises for text processing on the command line.
  • Bioinformatics for Beginners NIH Bioinformatics Training and Education Program. Bulk RNA-seq from raw reads to pathways, with practice sets. Course page
  • Bioinformatics Learning Roadmap Talha Raziq. I use it for Python libraries, advanced RNA-seq designs and single-cell analysis with Scanpy. GitHub

Projects

Each block of reading ends in a small project on public data, so that what I learn turns into something I can show and someone else can rerun.

  4. Single-cell basics with ScanpyPlanned Clustering and marker genes on public 10x data, and a check of whether the counts are really zero-inflated. December 2026.
